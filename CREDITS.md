# Credits

loopboard's code is original work under this repo's [MIT license](LICENSE).

The agent skills in [`.agents/skills/`](.agents/skills/) are partly copied or
adapted from [mattpocock/skills](https://github.com/mattpocock/skills) by Matt
Pocock (MIT). Which ones, what changed, and both license notices:
[`.agents/skills/CREDITS.md`](.agents/skills/CREDITS.md). That file ships with
the skills, so every repo set up with `loopboard init` keeps the notices.

The Help Center's course ([`docs/learn/`](docs/learn/)) builds on Matt Pocock's
ideas — grilling, PRDs and issues as vertical slices (tracer bullets),
feedback loops and the smart zone — and links his
[videos](https://www.youtube.com/@mattpocockuk) and
[writing on AI Hero](https://www.aihero.dev/skills). They're his; the course
links to them and loads YouTube only when you press play.

The course videos are rendered with [Remotion](https://www.remotion.dev)
(source-available, [Remotion License](https://www.remotion.dev/license)) from
[`videos/`](videos/); only the rendered MP4s ship, not Remotion.

The interface bundles [Inter](https://rsms.me/inter/) and
[JetBrains Mono](https://www.jetbrains.com/lp/mono/) (both SIL Open Font
License 1.1, via Fontsource) and icons from [Lucide](https://lucide.dev)
(ISC). Their licenses ship inside the packages in `node_modules`.

Thank you!
