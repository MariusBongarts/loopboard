# Skill credits

These skills ship with [loopboard](https://www.npmjs.com/package/loopboard)
(MIT). `implement`, `triage`, `issue-grooming` and `upgrade-harness` are
loopboard originals;
the others are copied or adapted from
[mattpocock/skills](https://github.com/mattpocock/skills) by Matt Pocock (MIT).
This file travels with the skills when `loopboard init` copies them, so the
license notices stay with every copy.

| Skill | Origin | Changes |
|---|---|---|
| `grill-me` | [mattpocock/skills](https://github.com/mattpocock/skills) `grill-me` | Copied; description reworded |

| `to-prd` | [mattpocock/skills](https://github.com/mattpocock/skills) `to-prd` (now `to-spec`) | Rewritten to create a project folder with `prd.md` + `wip.md` |
| `to-issues` | [mattpocock/skills](https://github.com/mattpocock/skills) `to-issues` (now `to-tickets`) | Rewritten for local `.agents/issues/` files, statuses and assignee |
