Brand Kit

Warm paper, ink and one ember accent: an editor's desk, not a dashboard. Everything on this page is rendered from src/styles.css — change a token there and this page changes with it.

Rules

  • Tokens only. Colors come from the CSS custom properties below; never hard-code a color. Mixes use color-mix(in oklch, var(--token) N%, …). Both themes must pass pnpm contrast (WCAG AA for text and status/project chips).
  • One accent. Ember marks the primary action, the current selection and the brand. Tones (ember, blue, moss, rose, plum, amber, teal) are identity colors for projects and labels — never decoration.
  • Type has jobs. Fraunces (serif) for titles and reading text, Geist (sans) for interface, JetBrains Mono for ids, paths and keys.
  • Quiet by default. Hover reveals secondary actions (pin, copy prompt); badges appear only when they say something (waiting, reviewed, deployed).
  • Plain words, sentence case. "Needs you", "Copy agent prompt", "Changed on disk". Say what happens, not how it works. No exclamation marks.
  • Keyboard first. Every new action gets a ⌘K command; plain-key shortcuts go in src/shortcuts.ts so Help lists them.
  • Dialogs use BaseDialog; segmented choices use Segmented; confirmations are inline ("Remove… → Remove / Keep"), not native confirm().
