## User story

As a **maintainer**, I want a right-click menu on any issue card or row, so that common actions are one click away.

## Acceptance criteria

- [x] Cards, list rows and feed issue rows open the `Menu` at the pointer
- [x] Items: Status ▸, Assignee ▸, Labels ▸, Project ▸, Open page, Open in editor, Copy agent prompt, Copy path, Copy link, Send to backlog / Mark reviewed
- [x] Keyboard accessible (context-menu key / Shift+F10 on a focused card or row)
- [x] Spec § 4 scenario and e2e
