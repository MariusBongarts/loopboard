## User story

As a **maintainer**, I want **dots on what is new since I last looked, and a Mark all seen action**, so that **I see at a glance what changed**.

## Acceptance criteria

- [ ] Runs after the last-seen time, and sessions and issues of a later day, carry a dot
- [ ] Mark all seen stores now as last seen for this workspace in this browser; with none, the last 24 hours count as new
- [ ] The rail's Home entry shows the number of new items
- [ ] Vitest for what counts as new

## Out of scope

- Last seen across devices (the server stays read-only)
