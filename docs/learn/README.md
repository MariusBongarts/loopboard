# Working with AI agents

A short course on the workflow loopboard is built around — why it makes coding
agents dependable, step by step. In the app it's under Help → Working with AI
agents, with a short video per chapter.

1. [Agents forget, the repo remembers](01-memory.md)
2. [Skills: instructions on demand](02-skills.md)
3. [Grill me: agree before you build](03-grill.md)
4. [The PRD: write the contract down](04-prd.md)
5. [Issues: thin vertical slices](05-slices.md)
6. [The issue loop](06-loop.md)
7. [Feedback loops keep agents honest](07-feedback.md)
8. [You steer from the board](08-steer.md)

Much of this comes from Matt Pocock: the skills are adapted from
[mattpocock/skills](https://github.com/mattpocock/skills), and his
[videos](https://www.youtube.com/@mattpocockuk) and
[AI Hero articles](https://www.aihero.dev/skills) go deeper.
